# Googleスプレッドシート連携の設定手順

診断を終えた人の結果を、Googleスプレッドシートに1行ずつ自動で記録します。
スプレッドシートの「タイプ集計」シートで、どのタイプが何％かをグラフ付きで確認できます。
診断ページの管理者用ダッシュボードからも同じデータを見られます。

> この連携は、診断ページを一般のWebサイト（GitHub Pages など）に置いた場合に使えます。
> claude.ai で公開したページからは外部に送信できないため、そちらはページ内の保存機能を使います。

所要時間は10分ほどです。

## 1. スプレッドシートを作る

1. [Googleスプレッドシート](https://sheets.new) で新しいスプレッドシートを作ります。
2. 名前を付けます（例：「子育てタイプ診断 回答」）。

## 2. Apps Script を貼り付ける

1. メニューの **拡張機能 → Apps Script** を開きます。
2. 最初からある `コード.gs` の中身をすべて消し、このリポジトリの [`gas/Code.gs`](../gas/Code.gs) の中身をすべて貼り付けます。
3. 保存ボタン（💾）を押します。

## 3. 初期設定を実行する

1. 画面上部の関数の選択欄で **`setup`** を選び、**実行** を押します。
2. 初回は権限の確認が出ます。「権限を確認」→ 自分のアカウントを選択 →（「このアプリは Google で確認されていません」と出た場合）「詳細」→「（プロジェクト名）に移動」→「許可」と進みます。
3. 実行が終わると、下の **実行ログ** に `管理者キー: ……` と表示されます。**このキーを控えておいてください。** ダッシュボードを開くときに使います。

スプレッドシートに戻ると、「回答」シート（見出し行）と「タイプ集計」シート（表とグラフ）ができています。

## 4. ウェブアプリとして公開する

1. Apps Script の右上の **デプロイ → 新しいデプロイ** を押します。
2. 種類の選択（⚙）で **ウェブアプリ** を選びます。
3. 次のように設定します。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. **デプロイ** を押し、表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピーします。

「アクセスできるユーザー：全員」は、診断ページから結果を送れるようにするための設定です。
回答データを読み出せるのは管理者キーを知っている人だけで、スプレッドシート自体が公開されるわけではありません。

## 5. 診断ページにURLを設定する

[`js/config.js`](../js/config.js) の `SHEETS_ENDPOINT` に、コピーしたURLを貼り付けます。

```js
const SHEETS_ENDPOINT = "https://script.google.com/macros/s/xxxxxxxx/exec";
```

（URLを伝えてもらえれば、こちらで設定してプッシュすることもできます。）

## 6. 診断ページを公開する

GitHub Pages を使う場合は、リポジトリの **Settings → Pages** で、公開するブランチ（例：`main`）とフォルダ（`/ (root)`）を選んで保存します。
数分後に表示されるURLが診断ページです。

## 7. 動作を確認する

1. 診断ページで50問に答えて結果を表示します。
2. スプレッドシートの「回答」シートに1行増え、「タイプ集計」シートの数字が更新されていれば成功です。
3. 管理者用ダッシュボードは、診断ページのURLの末尾に `#admin` を付けて開き（例：`https://…/index.html#admin`）、手順3の管理者キーを入力します。

## スプレッドシートの中身

**回答シート**（1回の診断 = 1行）

| 列 | 内容 |
|---|---|
| 日時 | 記録した日時 |
| 回答者ID | ブラウザごとに作る匿名のID。同じ人が何度診断しても同じIDになる（別の端末やブラウザでは別ID） |
| タイプキー / タイプ | 診断結果 |
| 判定方法 | `score`（スコアの差で決定）、`core`・`strong`・`first-split`（僅差のため比較ルールで決定）、`choice`（本人が選択） |
| 回答が均一 | 注意メッセージが出た回答かどうか |
| 学び〜安定 | 5軸のスコア（0〜100） |
| Q1〜Q50 | 回答（かなりそう思う=2、そう思う=1、なんとも言えない=0、そう思わない=-1、かなりそう思わない=-2） |

**タイプ集計シート**（回答が届くたびに自動更新）

- 回答者数（1人につき最新の結果を1件として数える）と、その割合
- 診断回数（すべての診断）と、その割合
- 回答者ごとの割合の棒グラフ

名前やメールアドレスは記録しません。

## よくある操作

- **管理者キーを忘れた**：Apps Script でもう一度 `setup` を実行すると、実行ログに表示されます（キーは変わりません）。
- **管理者キーを変えたい**：Apps Script の **プロジェクトの設定 → スクリプト プロパティ** で `ADMIN_KEY` の値を書き換えます。
- **Code.gs を更新した**：**デプロイ → デプロイを管理** → 編集（✏）→ バージョン「新バージョン」→ デプロイ。URLは変わりません。
- **テストで入れた行を消したい**：「回答」シートの行を削除してください。「タイプ集計」は次の回答が届いたとき、または `setup` を実行したときに更新されます。
