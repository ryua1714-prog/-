# 子育てタイプ診断

50問の質問に5段階で答えると、子育ての価値観を8つのタイプで診断するWebツールです。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド・サーバー不要）。GitHub Pages などの静的ホスティングにもそのまま置けます。

## 構成

- `content/questions.md` … 50問の質問文とタイプ判定用の配点（正式原稿）
- `content/results.md` … 8タイプの結果文章（正式原稿）
- `tools/build_content.py` … 上の2つから `js/content.js` を生成（原稿の文字は加工しない）
- `tools/calibrate.js` … タイプごとの補正値を計算し、各タイプの出やすさを検証
- `js/content.js` … 生成された質問・配点・結果文章（直接編集しない）
- `js/data.js` … 回答選択肢、8タイプ（コア質問・中心思想・色）、補正値、5軸の質問割り当て
- `js/scoring.js` … タイプ判定・5軸の計算（画面に依存しない）
- `js/storage.js` … 診断結果の保存（claude.ai で公開したページの db 機能）
- `js/dashboard.js` … 管理者用分析ダッシュボード
- `js/app.js` … 画面制御、レーダーチャート描画
- `css/style.css` … スタイル（スマホ対応・ダークモード対応・タイプ別カラー）

原稿を直したら `python3 tools/build_content.py` を実行してください。配点を変えたら `node tools/calibrate.js --write` で補正値を計算し直してください。

| 安心型｜保護者 | 🐨 | 淡いピンク〜ベージュ |

## タイプ判定

1. 回答値（かなりそう思う=+2 〜 かなりそう思わない=-2）の強さ × 配点を、肯定なら「肯定」側、否定なら「否定」側のタイプに加点して素点を出す（例：Q1「かなりそう思う」→ 教育+4・挑戦+2）
2. 素点を正規化する。その人の回答の並びだけを入れ替えたときの素点の平均・標準偏差を基準にして `50 + 10 × (素点 − 平均) ÷ 標準偏差` とする。全体に「そう思う」寄りに答える人でも、共感されやすい質問の多いタイプだけが有利にならない
3. 正規化スコアにタイプごとの補正値（`CALIBRATION`）を足し、最も高いタイプを結果とする。補正値は `tools/calibrate.js` で想定回答者集団に対して各タイプが12.5%になるよう求めた固定値で、同じ回答なら常に同じ結果になる
4. 上位2タイプの差が3ポイント未満なら、次の順で比較する
   1. コア質問（各4問）での、そのタイプ方向への回答強度の合計
   2. 「かなりそう思う」「かなりそう思わない」でそのタイプ方向へ強く振れた回答の数
   3. Q1から順に見て、2タイプへの点に最初に差がついた質問
5. それでも決まらない場合はランダムに決めず、`TIEBREAK_QUESTIONS` の二択質問（未定義なら2タイプの中心思想を並べて本人が選ぶ）で決める

### 均一回答の検出

次のいずれかに当てはまると、結果の前に注意メッセージを表示します（「このまま結果を見る」「初めから診断する」）。

- 「なんとも言えない」が45問以上
- 同じ回答（どの選択肢でも）が45問以上

## 5軸レーダーチャート

タイプ判定とは別に、回答から直接計算します。各軸に肯定方向・否定方向の質問を割り当て、`50 + 50 × (肯定方向の平均 − 否定方向の平均) ÷ 4` で0〜100にします（すべて「なんとも言えない」なら50）。肯定側と否定側を同じ重みで扱うので、全体に「そう思う」寄りに答えても特定の軸だけが高くなりにくくなっています。

| 軸 | 肯定方向 | 否定方向 |
|---|---|---|
| 学び | Q1, 4, 11, 12, 17, 25, 31, 34, 42, 48, 50 | Q15, 22, 30, 38, 40 |
| 個性 | Q2, 6, 10, 15, 22, 24, 29, 31, 35, 38, 39, 40, 45, 49 | Q3, 4, 14, 17, 21, 28, 34, 48, 50 |
| 成長 | Q5, 7, 8, 13, 18, 19, 20, 26, 27, 32, 37, 41, 43, 46 | Q23, 36, 44, 47 |
| 礼儀 | Q3, 14 | Q9, 24, 35, 39 |
| 安定 | Q16, 28, 30, 33, 36, 44, 47 | Q1, 5, 8, 11, 13, 19, 25, 26, 27, 29, 32, 42, 45 |

## 回答データの保存と管理者用ダッシュボード

claude.ai のアーティファクトとして公開したページでは、診断を最後まで終えると結果が保存されます（ファイルを直接開いた場合や一般的なWebサーバーでは保存されません）。

- 保存先: `responses/<回答者ID>`。1人1件で、最新の結果と直近20回分の診断（タイプ、判定方法、50問の回答、5軸、均一回答かどうか、日時）を持つ
- 回答者IDは claude.ai が発行する匿名のIDで、名前やメールアドレスは保存しない
- 回答者が書き込めるのは自分の分だけ。全員分を読めるのは管理者（編集者・オーナー）だけ
- 保存できるのは Contributor 以上の権限で開いた人（組織のメンバーなど）。閲覧のみ（Viewer）の人や組織外の人は、診断はできても結果は保存されない

管理者がページを開くと「管理者ダッシュボードを開く」が表示されます（URL末尾に `#admin` を付けても開けます）。タイプ別の割合（回答者ごと／すべての診断、全期間／30日／7日）、5軸の平均、質問ごとの回答分布を確認できます。
