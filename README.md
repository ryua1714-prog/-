# 子育てタイプ診断

31問の質問に5段階で答えると、子育ての価値観を8つのタイプで診断するWebツールです。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド・サーバー不要）。GitHub Pages などの静的ホスティングにもそのまま置けます。

## 構成

- `index.html` … スタート / 質問 / 均一回答の確認 / 同点時の二択 / 結果 の各画面
- `js/data.js` … 質問とウェイト、回答選択肢、5軸、8タイプの内容・識別質問・タイプカラー、同点用の二択質問
- `js/app.js` … タイプ判定、均一回答の検出、レーダーチャート描画、画面制御（判定のしきい値は冒頭の `CONFIG`）
- `css/style.css` … スタイル（スマホ対応・ダークモード対応・タイプ別カラー）

## 判定ロジック

1. 回答値（かなりそう思う=+2 〜 かなりそう思わない=-2）× 各質問のタイプウェイト をタイプごとの素点に加算（Q31を含む全31問）
2. タイプごとに maxAbs（ウェイトの絶対値 × 2 の合計＝理論上の最大絶対点）を求め、`normalized = ((raw / maxAbs) + 1) / 2 * 100` で0〜100に正規化
3. normalizedが最も高いタイプをメインタイプとする
4. 1位と2位の差が3ポイント未満なら、次の順で比較し、差がついた時点で決定（`CLOSE_RULES`）
   1. 自タイプの識別質問（各3問）から得た寄与点の合計
   2. Q31を除いた30問だけで再計算したnormalized
   3. 「かなりそう思う」「かなりそう思わない」から得た絶対寄与点
   4. 両タイプの識別質問を質問番号順に見て、最初に寄与点の差が生じたタイプ
5. それでも決まらない場合はランダムに決めず、`TIEBREAK_QUESTIONS` の二択質問（未定義なら2タイプの考え方を並べて本人が選ぶ）で決める

全タイプのスコアは `diagnose()` の `typeScores` に保持していますが、画面には表示しません。

### 均一回答の検出

次のいずれかに当てはまると、結果の前に確認画面を表示します（「このまま結果を見る」「回答を見直す」）。

- 30問すべて同じ回答
- 「なんとも言えない」が24問以上
- 回答値の標準偏差が0.5未満、かつタイプ間normalizedの最大差が12.5未満

### 5軸レーダーチャート

8タイプ判定とは別に計算します。通常方向の質問は かなりそう思う=100 / そう思う=75 / なんとも言えない=50 / そう思わない=25 / かなりそう思わない=0、逆方向の質問はその反対で点数化し、軸ごとに平均します。

| 軸 | 通常方向 | 逆方向 |
|---|---|---|
| 学び | Q1, Q8, Q9, Q16, Q24, Q25, Q31 | － |
| 個性 | Q2, Q3, Q10, Q11, Q18, Q20, Q30 | Q21, Q29, Q31 |
| 成長 | Q4, Q7, Q12, Q15, Q19, Q20 | Q22, Q23, Q28 |
| 礼儀 | Q5, Q13, Q21, Q29 | － |
| 安定 | Q6, Q14, Q17, Q22, Q23, Q28 | Q4, Q19 |
