# 子育てタイプ診断

30問の質問に5段階で答えると、子育ての価値観を8つのタイプで診断するWebツールです。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド・サーバー不要）。GitHub Pages などの静的ホスティングにもそのまま置けます。

## 構成

- `index.html` … スタート / 質問 / 均一回答の確認 / 同点時の二択 / 結果 の各画面
- `js/data.js` … 質問と重み、回答選択肢、5軸、8タイプの内容・識別質問・タイプカラー、同点用の二択質問
- `js/app.js` … タイプ判定、均一回答の検出、レーダーチャート描画、画面制御（判定のしきい値は冒頭の `CONFIG`）
- `css/style.css` … スタイル（スマホ対応・ダークモード対応・タイプ別カラー）

## 8タイプ

| タイプ | イラスト | カラー |
|---|---|---|
| 教育型｜設計者 | 🦉 | ネイビー〜ブルー |
| 個性型｜プロデューサー | 🐈 | パープル〜ラベンダー |
| 自立型｜相談役 | 🐴 | グリーン〜青緑 |
| 挑戦型｜応援団長 | 🐒 | オレンジ |
| 社会型｜指導者 | 🐕 | イエロー〜ゴールド |
| 安心型｜保護者 | 🐨 | 淡いピンク〜ベージュ |
| 努力型｜監督 | 🐯 | 赤〜深いオレンジ |
| 戦略型｜戦略家 | 🦊 | ブルーグレー〜ティール |

## 判定ロジック

1. 回答値（かなりそう思う=+2 〜 かなりそう思わない=-2）× 各質問の重み をタイプごとに加算
2. タイプごとに「設定されている重みの絶対値の合計」で割って normalized score を算出し、最も高いタイプを結果とする
3. 1位との差が `CONFIG.nearTieMargin`（0.05）以内のタイプがあれば、候補タイプの識別質問（各2問）の平均回答値で比較
4. それでも完全同点なら `TIEBREAK_QUESTIONS` に定義した二択質問を出題する。未定義の組み合わせは、候補タイプの考え方を並べて本人に選んでもらう

全タイプのスコアは `diagnose()` の `typeScores` に保持していますが、画面には表示しません。

### 均一回答の検出

次のいずれかに当てはまると、結果の前に確認画面を表示します（「このまま結果を見る」「回答を見直す」）。

- 30問すべて同じ回答
- 「なんとも言えない」が24問以上
- 回答値の標準偏差が0.5未満、かつタイプ間スコアの最大差が0.5未満

### 5軸レーダーチャート

各軸の対象質問を かなりそう思う=100 / そう思う=75 / なんとも言えない=50 / そう思わない=25 / かなりそう思わない=0 に変換して平均します（マイナスの重みは使いません）。
