# 子育てタイプ診断

30問の質問に5段階で答えると、子育ての価値観を8タイプの動物で診断するWebツールです。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド・サーバー不要）。GitHub Pages などの静的ホスティングにもそのまま置けます。

## 構成

- `index.html` … スタート / 質問 / 結果の3画面
- `js/data.js` … 質問・回答選択肢・8タイプの内容・5軸の定義
- `js/app.js` … スコア計算、レーダーチャート描画、画面制御
- `css/style.css` … スタイル（スマホ対応・ダークモード対応）

## 判定ロジック

- 回答点数：かなりそう思う=5 〜 かなりそう思わない=1
- 8タイプ：各タイプの対象質問の平均点を計算し、最も高いタイプを結果とする
  - 同点の場合は フクロウ → ネコ → 馬 → サル → イヌ → コアラ → トラ → キツネ の順で先のタイプを優先
  - 全タイプのスコアは内部で保持（`diagnose()` の `typeScores`）するが、画面には表示しない
- 5軸（学び・個性・成長・礼儀・安定）：対象質問の平均点を `((平均 - 1) / 4) × 100` で0〜100に変換し、五角形のレーダーチャートで表示
